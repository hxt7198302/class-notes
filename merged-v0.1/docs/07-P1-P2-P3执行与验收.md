## P1 · 上传协议统一（后端）

目标：让原作者 v2.12 的 APP 上传/读取契约在云后端（webapp）落地，数据写入规范目录。

接口（统一鉴权 x-app-token；token 存 webapp/data/api-token.txt，首次自动生成；开发可用 APP_TOKEN 覆盖）：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/session/meta | 登记/续传元数据，返回各文件已收字节 |
| POST | /api/chunk?id=&name=&offset=&md5= | 原始字节追加；偏移不符 409（返回服务端 size）；md5 不符 422 |
| POST | /api/session/complete?id= | 收尾，写 complete.flag 与 status.json |
| GET | /api/notes | 笔记/会话列表 |
| GET | /api/note?id= | 单篇（meta/status/note/items） |
| GET | /api/source?id= | 原始素材（分段/照片/文字稿） |
| GET | /api/file?id=&name= | 文件读取（支持 Range） |

存储：webapp/data/agent/<会话ID>/meta.json、files/、status.json、note.md

验收：
- tests/agent-api-smoke.js 全绿（分块/续传/409/422/complete/list/note/source/file+Range）
- 旧路由不回归（health、classes、assist 等仍 200）
