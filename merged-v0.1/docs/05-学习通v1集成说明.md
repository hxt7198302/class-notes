## 二、合并后的链路

    Android APP（WebView 壳）
        │ 打开 Web UI
        ▼
    webapp（云端 Node）
        │ GET/POST /api/chaoxing/*
        ▼
    pc-agent（用户自己的 Windows 电脑）
        ├─ Node 8776（鉴权、代理）
        └─ Python sidecar 127.0.0.1:8781
              ▼
           学习通（只读）

- webapp 新增代理路由（本次已实现）：
  GET  /api/chaoxing/status
  GET  /api/chaoxing/login/status
  POST /api/chaoxing/login/start
  GET  /api/chaoxing/summary（支持 force=1）
  POST /api/chaoxing/logout
  POST /api/chaoxing/verify/open
- 地址配置：webapp/.env 的 CHAOXING_SIDECAR，默认 http://127.0.0.1:8781
- sidecar 未启动时，webapp 返回可读错误，前端显示「需本机 pc-agent 在线」，不影响其他功能

## 三、使用前提（硬约束）

1. 用户有一台 Windows 电脑，开机且 pc-agent 服务在运行
2. 手机与电脑在同一局域网，或电脑端隧道可达
3. 扫码时二维码显示在电脑屏幕上（手机扫电脑屏幕）
4. 账号为单账号；换账号先退出

## 四、边界（必须写进 README/产品说明）

- 只读：不签到、不刷课、不自动答题、不自动提交
- 不存账号密码：扫码登录；APP 不接触密码框
- 登录态只存用户本机 pc-agent（data/chaoxing/session_cookies.json），不上传云端、不入库
- 触发人机验证时停下，由用户本人在电脑输入验证码
- 「没取到」不等于「没作业/已完成」，UI 必须区分
