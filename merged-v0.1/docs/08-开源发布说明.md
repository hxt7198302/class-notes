# 08 · 开源发布说明（公开脱敏快照）

日期：2026-10-24
性质：交付给项目作者发布到 GitHub 的公开版本。

## 一、本快照包含

- webapp/：统一 Web UI + 云后端（AI 助教 / 教务导入 / OCR / 课表 / 上传协议 / 学习通代理）
- pc-agent/：电脑端能力模块（GPU 转写 / AI 成稿 / 学习通 v1 / 素材修复）
- app-android/：安卓 WebView 壳 + 原生录音桥源码
- docs/：架构决策、后端对比、数据契约、API 映射、学习通集成、发布清单、P1-P3 验收
- 测试：webapp/tests/（上传协议冒烟 + 演示数据生成器）

## 二、本快照不包含（已移除）

| 内容 | 原因 |
|---|---|
| 旧版原生安卓源码 | 与合并产品无关；且含旧品牌信息 |
| 私有 AI 分析手册、zcode 私有引擎 | 作者私有资产 |
| 真实课堂数据、素材、笔记 | 隐私 |
| .env / api-token / 学习通 Cookie / 密钥 | 安全 |
| 模型文件、node_modules、构建产物、APK | 体积与分发规范（APK 走 Releases） |
| 内部需求单、内部对比文档、历史备份 | 内部资料 |
| 个人绝对路径、个人设备信息、隧道地址 | 隐私与可移植性 |

## 三、使用前配置

1. webapp/.env：复制 .env.example，填 ZHIPU_API_KEY / DEEPSEEK_API_KEY（可选 CHAT_PIN 访问口令）
2. pc-agent/config.json：复制 config.example.json（可选能力端）
3. 安卓：设置 CLASSROOM_JDK、CLASSROOM_SDK 环境变量后运行 app-android/build-apk.ps1

## 四、隐私与合规

- 本快照经 5 轮对抗式审查 + 自动化扫描：无姓名/手机号/邮箱/学号、无密钥/Token/Cookie、无个人绝对路径、无真实数据。
- 学习通 v1 为只读实现；使用需遵守服务条款与学校规定。
- 提交前建议再跑一次 docs/06-GitHub发布清单.md 的扫描命令。
