# 03 · 统一数据契约（v1 草案）

> 原则：以原作者 v2.12 的 meta.json / status.json / items.json 为**真源**（经 67+ 篇真实笔记验证），云后端只做**扩展字段**，不丢字段。
> schemaVersion：1

## 一、会话 ID

- 规范：cYYYYMMDD-HHMMSS-xxxx（原作者规则，语义化）
- 旧 ID（Web 版 smv*）迁移时保留 legacyId 字段，不重命名历史文件

## 二、目录布局

pc-agent（保持不变）：

    素材/<会话ID>/meta.json
    素材/<会话ID>/files/recording_XX.m4a | *.jpg
    笔记/<会话ID>/status.json | note.md | note.html | items.json | research/

webapp（P1 目标，新增 agent 数据区）：

    data/agent/<会话ID>/meta.json | status.json | note.md | note.html | items.json
    data/agent/<会话ID>/files/...
    data/sessions/<旧id>/            # 兼容旧 Web 数据，只读迁移源

## 三、meta.json（会话元数据）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 会话 ID（规范见上） |
| schemaVersion | int | 新增，固定 1 |
| course | string | 课程名（≤40） |
| courseId | string | 可选，Web 版课表课程 ID |
| teacher / room | string | 可选，展示用 |
| startedAt / endedAt | number | epoch 毫秒 |
| durationMs | number | 总时长 |
| device | string | 设备型号 |
| segments[] | array | {name, startOffsetMs, srcId?} |
| photos[] | array | {name, offsetMs, takenAt?, srcId?, bytes?} |
| markers[] | array | {offsetMs, type, note, createdAt?} |
| repairing / mergeDirty / mergedInto / members[] | 兼容字段 | 与 v2.12 同名同义 |
| transcript | object | 扩展：{text, segments[{s,e,t}], model, tookMs, at, polished} |
| transcriptStatus / transcriptError | string | 扩展：异步转写状态 |
| aiNote | object | 扩展：{title, markdown, items[]} |
| createdAt / updatedAt | number | 扩展 |
| deleted | bool | 扩展：软删除（可选） |

## 四、status.json（处理状态）

| 字段 | 说明 |
|---|---|
| state | uploading / uploaded / queued / transcribing / analyzing / done / error |
| course / title / summary | 列表展示 |
| progress | 0–100 |
| error / note | 错误与说明 |
| permanentFailure | 永久失败（内容安全等） |
| mergedInto | 已并入的锚点会话 |
| updatedAt | ISO 时间 |

## 五、items.json（待办事项）

| 字段 | 说明 |
|---|---|
| title | 事项名 |
| category | 作业 / 考试 / 比赛 / 社团 / 通知 / 生活 / 其他 |
| due | YYYY-MM-DD 或空（禁止乱填） |
| urgent | bool |
| quote | 老师原话（出处） |
| offsetSec | 录音内秒数 |
| research / researchQuery | 是否需要查资料 |
| done | 扩展：完成状态（可选） |

## 六、迁移映射（Web 版 → 规范）

| Web 版字段 | 规范字段 |
|---|---|
| id（smv*） | id 保留 + legacyId |
| courseId | courseId |
| courseName | course |
| segments[].offsetMs | segments[].startOffsetMs |
| photos[].bytes | photos[].bytes |
| markers[].type/note | 同名字段 |
| note | 会话备注（与 note.md 区分） |
| transcript | transcript |
| aiNote | aiNote |
| status | status.json.state |
| startedAt/endedAt/durationMs | 同名字段 |

## 七、兼容规则

1. 读写必须保留未知字段（扩展优先，不覆盖）。
2. 迁移脚本只增不改源文件；源目录备份后只读。
3. 时间一律 epoch 毫秒；展示层本地化。
