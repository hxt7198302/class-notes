课表管理

导入课表

四种导入方式教程
① 教务账号登录（推荐）
  1. 我的 → 导入课表 → 账号
  2. 选学校系统：北物资 / 正方 / 强智
  3. 正方、强智要填教务系统网址（浏览器打开登录页，复制地址栏）
  4. 输入学号 + 密码（信息门户密码）
  5. 点「登录并拉取课表」，等 5-20 秒
  6. 核对课程列表，点「合并导入」或「替换全部」
登录失败：密码不对或学校要验证码，改用 ③④；提示"网络访问不到"就用本机地址 http://127.0.0.1:3003
② 截图识别
  1. 在教务系统课表页截图（课程名/教室/节次/周次清晰）
  2. 导入课表 → 截图 → 点框选上传
  3. 点「AI 识别」，等 10-30 秒
  4. 核对（可点「改」修正），再导入
识别漏课：截全屏或分两张识别；AI 较慢，请耐心等
③ CSV / WakeUp
  1. 在 WakeUp 课程表里导入/填好课表
  2. WakeUp 课表页 → 右上角下载 → Excel 导入 → 导出 CSV
  3. 课堂助手 → 导入课表 → CSV → 上传文件
  4. 核对后导入
表头必须含：课程名称,星期,开始节数,结束节数,老师,地点,周数（老师/地点空着填「无」）
④ HTML 导入（通用）
  1. 电脑浏览器登录教务系统（扫码/密码都行）
  2. 打开课表页，等课表完全显示
  3. 按 Ctrl+S 保存，类型选「网页，仅 HTML」
  4. 导入课表 → HTML → 上传保存的文件
  5. 核对后导入
解析不到：保存的可能是登录页或空壳页面，改用截图识别

用教务账号自动拉取课表（推荐，更准更快），或上传截图识别
